TASK 1: PostgreSQL + pgvector Setup
Priority: CRITICAL
Effort: 4 hours
Deadline: Tuesday EOD

Steps:
1. Set up PostgreSQL instance
   Option A: Docker
   $ docker run -p 5432:5432 -e POSTGRES_PASSWORD=postgres pgvector/pgvector:latest

   Option B: Local install
   Download from postgresql.org

2. Create database
   $ psql -U postgres -c "CREATE DATABASE narrativewatch;"

3. Enable pgvector
   $ psql -U postgres -d narrativewatch -c "CREATE EXTENSION vector;"

4. Create src/database/postgres_client.py
   - SQLAlchemy connection pool
   - Connection management
   - Error handling

5. Create src/database/models.py
   - Define ORM models:
     * InstagramPost
     * InstagramPage
     * Campaign
     * BiasPattern
     * AnalysisResult
   - Add Vector columns for embeddings

6. Create scripts/init_db.py
   - Initialize database schema
   - Create all tables
   - Create indices

7. Test it works
   $ python scripts/init_db.py
   $ pytest tests/test_database.py
