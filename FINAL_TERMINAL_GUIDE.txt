================================================================================
TROUBLESHOOTING
================================================================================

Frontend still shows 404:
  [SOLUTION] Clear browser cache
    1. Press Ctrl+Shift+Delete in browser
    2. Clear all cache
    3. Refresh page
    4. Or try incognito/private window

Port 3000 in use:
  [SOLUTION] Use different port
    npm run dev -- --port 3001
    Then go to http://localhost:3001

Port 8000 in use:
  [SOLUTION] Use different port
    python -m uvicorn src.app:app --port 8001

Dependencies error:
  [SOLUTION] Reinstall frontend packages
    cd frontend
    rm -rf node_modules package-lock.json
    npm install
    npm run dev

Backend won't import modules:
  [SOLUTION] Reinstall Python packages
    cd backend
    pip install -r requirements.txt --force-reinstall

PostgreSQL not running:
  [SOLUTION] Start PostgreSQL
    Windows: Services app → PostgreSQL → Start
    macOS: brew services start postgresql@15
