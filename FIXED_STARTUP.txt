================================================================================
TROUBLESHOOTING
================================================================================

If you still get "environment variable not defined":
  1. Make sure .env file exists in project root
  2. Check that .env is not empty
  3. Try: run_backend_simple.bat (uses Python for env loading)
  4. Or try: python backend/start_backend.py (manual)

If dependencies still fail to install:
  1. Delete venv folder in backend
  2. Try again - it will recreate it
  3. Or run manually:
     cd backend && python -m venv venv
     venv\Scripts\activate
     pip install uvicorn fastapi python-dotenv

If backend won't start on port 8000:
  1. Close any other apps using port 8000
  2. Edit backend/start_backend.py line with --port 8000
  3. Change 8000 to a different port (e.g., 8001)

If frontend won't start on port 3000:
  1. Close any other apps using port 3000
  2. Edit run_frontend.bat or frontend/vite.config.js
  3. Change port 3000 to something else

PostgreSQL not running?
  1. Open Windows Services (Win+R → services.msc)
  2. Find PostgreSQL service
  3. Right-click → Start
