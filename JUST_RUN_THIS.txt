================================================================================
IF SOMETHING GOES WRONG
================================================================================

1. PostgreSQL not running?
   - Open Services (Win+R → services.msc)
   - Find "PostgreSQL"
   - Right-click → Start

2. Port 8000/3000 already in use?
   - Edit run_backend.bat or run_frontend.bat
   - Change port numbers (e.g., 8001, 3001)

3. Dependencies error?
   - Delete the 'venv' folder in backend
   - Run RUN_EVERYTHING.bat again
   - It will recreate everything

4. Still stuck?
   - Check backend/logs/narrativewatch.log
   - Run: python backend/verify_config.py
   - Read: AUTOMATED_START.md (detailed guide)
