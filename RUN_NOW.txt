================================================================================
TROUBLESHOOTING
================================================================================

PostgreSQL not running?
  → Windows: Start PostgreSQL service from Services app (Win+R → services.msc)
  → Mac: brew services start postgresql@15
  → Linux: sudo service postgresql start

Port 8000/3000 in use?
  → Close other applications using those ports
  → Or edit scripts to use different ports

Dependencies error?
  → Run: pip install --upgrade pip
  → Then: pip install -r requirements.txt

Still stuck?
  → Check: backend/logs/narrativewatch.log
  → Verify: python verify_config.py
  → Read: AUTOMATED_START.md (detailed guide)
