================================================================================
TROUBLESHOOTING
================================================================================

Backend won't start:
  [SOLUTION] Make sure you're in the backend directory
    cd backend
    python -m uvicorn src.app:app --reload --port 8000

Port 8000 in use:
  [SOLUTION] Kill the process or use different port
    python -m uvicorn src.app:app --port 8001

Port 3000 in use:
  [SOLUTION] Run frontend on different port
    npm run dev -- --port 3001

"Module not found" errors:
  [SOLUTION] Install dependencies
    cd backend && pip install -r requirements.txt
    cd frontend && npm install

PostgreSQL not running:
  [SOLUTION] Start PostgreSQL service
    Windows: Services app → PostgreSQL → Start
    macOS: brew services start postgresql@15
    Linux: sudo service postgresql start

Cannot reach http://localhost:3000:
  [SOLUTION] Make sure both servers are running
    Backend: http://localhost:8000/health should work
    Frontend: npm run dev should show "Local: http://localhost:3000"
