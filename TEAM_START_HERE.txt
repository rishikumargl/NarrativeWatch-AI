                         WHAT IS THIS PROJECT?
================================================================================

Multi-agent system that analyzes Instagram pages to detect:
- Misleading content
- Emotional manipulation
- Bias (political, gender, ideological)
- Bot activity
- Coordinated influence campaigns

Built with:
- LangChain (agent orchestration)
- Vertex AI Gemini 2.5 (LLM - 20x cheaper than Claude/GPT-4)
- PostgreSQL + pgvector (vector database)
- Tavily Search (external research)

Deadline: 4 weeks (done by June 30, 2026)

================================================================================
                         QUICK SETUP (10 MINUTES)
================================================================================

STEP 1: Clone Repository
$ git clone https://github.com/rishikumargl/NarrativeWatch-AI.git
$ cd NarrativeWatch-AI

STEP 2: Create Your Environment
$ cp .env.example .env
# Edit .env and add your API keys (ask Rohan for credentials)

STEP 3: Switch to Your Branch
(Replace "your-branch-name" with your actual branch from above)
$ git checkout develop
$ git checkout -b your-branch-name

STEP 4: Install Dependencies
$ python -m venv venv
$ source venv/bin/activate  # Windows: venv\Scripts\activate
$ pip install -r requirements.txt

STEP 5: Verify Setup
$ python -c "import langchain; import sqlalchemy; print('OK')"

DONE! You're ready to start coding.

================================================================================
                         IMPORTANT RULES
================================================================================

1. NEVER commit API keys or secrets
   - Use .env.example as template
   - .env is in .gitignore (good!)

2. Always test before pushing
   - Run pytest
   - Check for console errors
   - Format code with black

3. Commit frequently
   - Multiple small commits >> one huge commit
   - Clear commit messages
   - One logical change per commit

4. Never push directly to main or develop
   - Always use feature branch
   - Create PR when done
   - Wait for review before merge

5. Pull before pushing
   - Reduces conflicts
   - Keeps code in sync
   - $ git pull origin develop (before pushing)

6. Ask for help early
   - Stuck > 30 minutes? Ask in #dev-help
   - Confused about task? Ask Rohan
   - Merge conflict? Ask for help

================================================================================
                         GETTING UNSTUCK
================================================================================

PROBLEM: "I don't understand my task"
SOLUTION:
  1. Read LLD_AND_TEAM_PLAN.md section for your agent
  2. Read IMPLEMENTATION_CHECKLIST.md for weekly tasks
  3. Ask Rohan to explain
  4. Pair program with teammate

PROBLEM: "My code doesn't work"
SOLUTION:
  1. Check error message carefully
  2. Google the error
  3. Add print statements / logging
  4. Ask #dev-help with error + what you tried
  5. Pair program if still stuck

PROBLEM: "I have a merge conflict"
SOLUTION:
  1. Run: git pull origin develop
  2. Look for <<<<<<, ======, >>>>>>
  3. Keep the code you want
  4. Ask for help if unsure

PROBLEM: "I don't know how to Git"
SOLUTION:
  1. Read BRANCH_GUIDE.md
  2. Ask Rohan
  3. Use these 5 commands daily:
     - git status
     - git pull
     - git add .
     - git commit -m "message"
     - git push

PROBLEM: "I'm lost on the big picture"
SOLUTION:
