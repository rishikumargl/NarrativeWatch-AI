6-STEP QUICK START (UPDATED FOR TWITTER)
================================================================================

Step 1: CREATE DATABASE
  psql -U postgres -c "CREATE DATABASE narrativewatch;"
  psql -U postgres -d narrativewatch -c "CREATE EXTENSION IF NOT EXISTS vector;"

Step 2: GET TWITTER CREDENTIALS
  Read TWITTER_API_SETUP.md
  Add to .env: TWITTER_BEARER_TOKEN=your_token

Step 3: VERIFY SETUP
  python backend/verify_config.py

Step 4: INSTALL & START BACKEND
  cd backend
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt
  python -m uvicorn src.app:app --reload --port 8000

Step 5: START FRONTEND (new terminal)
  cd frontend
  npm install
  npm run dev

Step 6: USE THE APP
  Frontend: http://localhost:3000
  Backend:  http://localhost:8000/docs
